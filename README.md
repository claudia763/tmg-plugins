# Multifamily Brokerage Plugin

The Multifamily Group's disposition toolkit for seller advisory work. Seven
skills, fully self\-contained (brand assets, templates, scripts, and playbooks
are bundled inside each skill).

## How to use this README

**This file intentionally contains no work instructions.** Each skill is
documented in its own folder — before doing any work, open that skill's
`SKILL.md` and follow it as the single source of truth. Skill docs change
often; anything summarized here would go stale. Do not rely on this file (or
any other top\-level file) for scoring settings, thresholds, model mechanics,
brand specs, or workflow steps — those live only in the skill folders.

## Skills

| Skill | Read this for work detail | What it covers |
| --- | --- | --- |
| Rent roll & T\-12 processing | `skills/SKILL.md` (see also `skills/README.md`) | Converting rent rolls and T\-12s into TMG's standardized underwriting workbooks |
| Underwriting | `skills/underwriting/SKILL.md` | Running a deal through the TMG Excel underwriting model |
| Sales comps | `skills/sales-comps/SKILL.md` | Sale Comparables package (Excel export \+ comp grid PDF) |
| Rent comparable analysis | `skills/rent-comparable-analysis/SKILL.md` | Rent comp set from the Dwellsy Comps API \+ branded deliverables |
| Loan terms lookup | `skills/loan-terms-lookup/SKILL.md` | Current estimated multifamily debt terms by lender/program |
| Broker valuation summary | `skills/broker-valuation-summary/SKILL.md` | The underwriting writeup (.docx seller advisory) |
| BOV deck | `skills/bov-deck/SKILL.md` | Broker Opinion of Value as an OM\-style PDF deck |

Each skill folder also carries its own `references/`, `scripts/`, and
`assets/` — the skill's `SKILL.md` explains when and how to use them.
